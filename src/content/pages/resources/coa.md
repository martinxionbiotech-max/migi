# Certificates of Analysis: What a Batch Record Should Tell You

**Quick Answer** — A CoA is a batch-level record: which tests were run on that lot, against which specification, with what result. Its purpose is traceability — connecting the kit in your hand to the manufacturing and quality system that released it. A CoA that lists only "conforms" without the tested parameters and criteria is a stamp, not a record.

## Fields that make a CoA useful

| Field | Why it matters |
|---|---|
| Product name and catalogue number | Confirms identity |
| Lot number | The link to the physical kit |
| Manufacturing and expiry date | Shelf-life verification |
| Test parameters | What was actually measured |
| Specification limits | Acceptance criteria used |
| Results | The measured values, not a summary verdict |
| Release signature and date | Authorisation |
| Reference to the specification document | Traceability of the criteria |

## What buyers do with it

1. **Release testing on receipt** — incoming inspection against the CoA, particularly for distributors with a quality system that requires it.
2. **Traceability during investigation** — when a result is disputed, the CoA establishes what was released and when.
3. **Tender and registration support** — evidence that batch release is controlled.
4. **Complaint handling** — a batch-level record allows comparison when a single lot underperforms.

## Requesting a batch certificate

Include the lot number printed on the kit, the catalogue number, and the date of receipt. Without the lot number a certificate cannot be issued, because the record is batch-specific.

## When something does not match

| Observation | Meaning | Action |
|---|---|---|
| Lot on CoA differs from kit | Traceability broken | Quarantine the kit; contact supplier |
| Expiry earlier than expected | Shelf-life at receipt reduced | Confirm acceptance criteria with supplier |
| "Conforms" with no parameters | Certificate not informative | Request the full version |
| Results outside specification with pass verdict | Internal contradiction | Request clarification before use |

## Six traps

1. **Accepting a CoA without the lot number.** Traceability is the point.
2. **Treating "conforms" as a complete record.** Parameters and criteria belong on it.
3. **Filing the CoA separately from the kit records.** The two must be linkable.
4. **Ignoring a lot change when trending a patient.** A shift can look like disease.
5. **Assuming conformance means comparability.** Within specification is a range, not a point.
6. **No incoming inspection.** Distributors with a quality system are expected to check.

## The Author's Take

**Position.** The CoA is the document that separates a manufacturer from a trader, and a buyer who knows how to read one can tell the difference in ten seconds.

**Reasoning.** Sellers who do not manufacture cannot produce a batch-specific record with parameters, criteria and release authorisation, and they know it — which is why so many supply a generic certificate or a "conformity" letter instead. Publishing a template on the website, with the fields visible in advance, tells a technical buyer which kind of supplier they are dealing with before the first email. It also sets an expectation that protects both sides: a distributor who has seen the template will ask for the lot number rather than complaining later that no record exists.
