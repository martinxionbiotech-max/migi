## How to run a comparison you can defend

1. Ask every vendor for the same items in writing — LoD with method, LoQ with CV target, precision at decision concentrations, reference intervals with sample size.
2. Run the same samples on each platform: one low, one mid, one high.
3. Compare with bias and limits of agreement, not correlation.
4. Check the reference interval on the demonstration unit.
5. Score the workflow, not only the instrument.

## The Author's Take

**Position.** The most persuasive page in a comparison section is the one that concedes ground — and it is also the one competitors find hardest to answer.

**Reasoning.** Buyers have read enough comparison tables to know that each was written by the party that wins it. A table that says "a strip is better for a binary triage decision" is believed precisely because it costs the author something. That credibility then transfers to the claims that follow, which is the entire mechanism by which technical marketing works — not by asserting superiority, but by being the source that does not overstate. In a market where every brochure claims completeness, restraint is the differentiating feature.
