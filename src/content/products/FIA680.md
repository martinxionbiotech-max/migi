# FIA680

The **Migibio FIA680** is a single-channel veterinary immunofluorescence quantitative analyzer engineered for point-of-care (POCT) diagnostics. It delivers rapid, precise, and fully quantitative results for a broad panel of canine and feline biomarkers.

## Key Features

- Single-channel fluorescence immunoassay detection

- Results in as fast as 3–11 minutes

- High sensitivity down to pg/ml (LOD)

- Excellent precision (CV% < 10%)

- Throughput of up to 200 tests per hour

- Multilingual interface (Chinese, English, Russian, Italian)

- Cloud chip technology for standard-curve download and custom reference ranges

- Built-in thermal printer for instant results


## Applications

Suitable for veterinary clinics, animal hospitals, breeding facilities, and on-site farm diagnostics — covering infectious disease antigen/antibody panels, hormones, and inflammatory markers.


## Technical Highlights

- **Three-step operation** for minimal training

- **Cloud standard curves** — recover lost ID chips over Wi-Fi

- **Online software updates**

- **A4 report generation** with hospital branding
