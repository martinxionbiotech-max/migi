## FIA880

The **Migibio FIA880** is a six-channel veterinary immunofluorescence quantitative analyzer built for high-throughput laboratories and multi-user clinics. It processes six samples simultaneously with independent channels, constant-temperature control, and precise timing.

### Key Features

- Six independent channels for simultaneous multi-sample testing

- Constant-temperature functionality for stable, reproducible results

- High throughput — up to 300 samples per hour

- Quantitative results with pg/ml-level sensitivity

- Multilingual interface (Chinese, English, Russian, Italian)

- Cloud chip technology with customizable standard curves

- Built-in thermal printer + A4 report export


### Technical Specifications

| Parameter | Specification |
|---|---|
| Channels | Six independent channels |
| Detection method | Fluorescence immunoassay |
| Result time | 3–15 minutes |
| Sensitivity | pg/ml (LOD) |
| Precision | CV% < 10% |
| Throughput | Up to 300 tests/hour |
| Temperature control | Constant-temperature |
| Languages | Chinese, English, Russian, Italian |
| Printer | Built-in thermal printer + A4 export |

### Applications

Ideal for medium-to-large veterinary hospitals, reference laboratories, and distributor networks requiring high-volume, multi-user operation without queuing.


### Technical Highlights

- **Six parallel channels** — no waiting between users

- **Precise temperature control** for quantitative accuracy

- **Online software updates**

- **Custom standard curves** per client reference ranges
